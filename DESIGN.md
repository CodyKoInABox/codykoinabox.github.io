# Design

Uma landing por locale (`/en`, `/pt`). Header de perfil + conteúdo abaixo.

- Geist, shadcn nova, paleta **neutral**, raio `0.625rem`.
- Light/dark via class no `<html>`. Toggle + fallback do sistema. Sem flash.
- Layout: max `1280px`. Avatar grande, nome, tagline, contato, botões (site / GitHub / LinkedIn), toggles de idioma e tema no canto.
- Sem dashboard, sem nav pesada, sem decoração. Motion só se for barato.
